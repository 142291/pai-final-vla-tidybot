## 注意

- **照明を一定に保つ。** 手首カメラの画角に窓とカーテンが入っている。昼と夜で明るさが変わると学習が不安定になる。
  録画はいつも同じ時間帯・同じ照明で行うか、窓を塞ぐ。
- カメラアームのポールが俯瞰の下端に写り込んでいるが、常に同じ位置なので実害はない。動かさないこと。
